# 美元汇率与锂电材料价格 · 每日自动更新

单页价格站的自动更新流水线：GitHub Actions 每天定时抓取公开数据，
重新生成 `index.html` 并提交回仓库，Netlify 从仓库自动发布。

## 仓库文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 发布的页面（由 `generate.py` 生成，不要手工改） |
| `template.html` | 页面模板（版式与 2026-10-29 上线版一致，数据处为占位符） |
| `data.json` | 历史序列存档：汇率、期货、磷酸铁锂、六氟磷酸锂序列 + 负极/隔膜最新已知值 |
| `generate.py` | 抓取 + 生成器（只用 Python 标准库，无需安装依赖） |
| `.github/workflows/daily-update.yml` | 每日定时任务 |

## 数据来源（每处数据在页面上均有来源标注）

| 数据 | 来源 | 更新方式 |
| --- | --- | --- |
| 美元兑人民币 | 欧洲央行每日参考汇率（经 Frankfurter 免费接口转发） | 每天自动更新，保留 90 天窗口 |
| 碳酸锂期货 | 新浪财经期货行情（广期所主力连续 LC0 日线） | 每天自动更新，保留最近 90 个交易日 |
| 磷酸铁锂 | 生意社磷酸铁锂参考价（`lfp.100ppi.com`） | 每天尽力抓取，抓不到保留上次值 |
| 六氟磷酸锂 | 生意社六氟磷酸锂（电池级）基准价 | 每天尽力抓取，抓不到保留上次值 |

## 运行时间

每个工作日 **16:00 UTC**，即北京时间**周二至周六 00:00**（UTC+8）。
选这个点是因为：已晚于广期所收盘（15:00 北京时间），且已晚于欧洲央行当日参考价发布
（约 16:00 CET/CEST），全年都覆盖。GitHub Actions 的 cron 可能延迟几分钟到几十分钟，
属于正常情况。

## 上线还缺的两步

1. **建 GitHub 仓库**：新建一个仓库（例如 `fx-lithium`），把本文件夹全部文件推上去。
2. **Netlify 改成 Git 自动部署**：在 Netlify 里新建站点并选择从 Git 导入该仓库
   （Build command 留空，Publish directory 留根目录），或把现有 `fx-lithium` 站点改成
   连接该仓库；站点名保持 `fx-lithium`，地址仍为 `https://fx-lithium.netlify.app/`。
   此后每天任务一提交，Netlify 自动重新发布，无需手动上传。

## 常见情况

- **某天某源抓不到**：生成器只告警、不中断，页面保留该品种上次已知值并标明日期，
  绝不编造数字；下次抓到后再更新。
- **生意社返回验证页**：生成器检测到验证页特征时视为抓取失败，保留上次值。
- **某天所有数据都没变**：工作流检测到 `git diff` 为空就不提交，Netlify 不重新发布。
- **新浪接口首次验证**：新浪日线接口在本机验证环境因域名策略屏蔽未能直接打开，
  接口形式有多份公开资料佐证；首次 Action 运行即为真实验证，若失败页面保持 10-29 快照值。
- **不使用 Cloudflare**：本方案全部走 GitHub Actions + Netlify，不依赖 Cloudflare。
